# ממסך אחד לכל מסך

יחידת למידה בעברית על רספונסיביות, לשילוב בשיעור של כ־35 דקות. מיועדת לסטודנטים שמכירים HTML ו־CSS ובנו אתרים בעבר, אך זקוקים לרענון ולא התנסו ברספונסיביות.

## מה כלול

- שישה פרקים: Viewport ומידות גמישות, Flexbox, Media Queries, תפריט לנייד, תמונות, טקסט ויחידות מידה.
- שש מעבדות HTML/CSS/JS: עריכה, הרצה, איפוס, הורדת קובץ HTML עצמאי ושינוי רוחב תצוגה בטווח 280–1200 פיקסלי CSS.
- 12 שאלות הבנה (שתיים בכל פרק), עם משוב ייחודי לכל אפשרות וניסיון חוזר. אין תרגיל סיום.
- כיוון RTL, רכיבי HTML סמנטיים, ניווט במקלדת, סימון מיקוד, הודעות משוב חיות, תמיכה בהעדפת תנועה מופחתת ובתצוגת הדפסה.
- עיצוב שממשיך את יחידת הדוגמה: גווני כחול, ניווט צדדי, כרטיסי הסבר ופעילות מדורגת. התיקייה `exsmpleLerningUnit` המקורית נשמרה ללא שינוי.

חלוקת הזמנים היא אומדן: 6 + 6 + 7 + 7 + 4 + 5 דקות. הרחבות סגורות בפרטים הן לבחירה ואפשר לדלג עליהן.

## הפעלה

פתחו את `index.html`. אין התקנה, בנייה, חשבון או שרת יישום. מומלץ לבדוק ולהפיץ באמצעות אתר סטטי, ובפרט GitHub Pages. לצורך עבודה מקומית אפשר להפעיל שרת קבצים פשוט מתוך התיקייה, למשל `python -m http.server 8080`, ולפתוח `http://localhost:8080`.

כל נכסי החובה מקומיים, כולל Bootstrap RTL 5.3.8. הדוגמאות עצמן הן וניל בלבד ואינן כוללות Bootstrap. קישורי MDN פותחים חומר הרחבה חיצוני לפי בחירת הלומדים. תמונת ההדגמה היא איור SVG בתוך הקוד, ללא שירות תמונות חיצוני.

## GitHub Pages

למאגר ייעודי, העלו את **תכולת התיקייה הזו** לשורש המאגר: `index.html`, שני קובצי JS, קובץ CSS, `assets` ו־`.nojekyll`. אפשר להשאיר גם את התיעוד. אין צורך להעלות את `.work` או את יחידת הדוגמה.

בהגדרות Pages של המאגר בחרו פרסום מהענף המתאים ומתיקיית השורש. לאחר הפרסום פתחו את כתובת האתר שמספק GitHub. אם האתר של המאגר כבר מתפרסם מהתיקייה שמעל יחידה זו, אפשר לשמור את היחידה כתיקייה ולפתוח את הנתיב `/ResponsiveLerningUnit/` תחת כתובת אותו אתר.

אין בקוד כתובות שמתחילות ב־`/` לנכסים מקומיים, ולכן הוא מתאים גם ל־Project Pages תחת נתיב מאגר. לא בוצעו יצירת מאגר, העלאה או פרסום בשם המשתמש.

עזרה רשמית: [הגדרת מקור הפרסום ב־GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## מבנה ותחזוקה

| קובץ | תפקיד |
| --- | --- |
| `index.html` | התוכן, הפרקים והמסגרת הסמנטית |
| `styles.css` | העיצוב, RTL, התאמות לרוחב ולהדפסה |
| `lessons.js` | הדוגמאות ושאלות ההבנה, כולל כל המשובים |
| `app.js` | ניווט, התקדמות, העורכים, ההרצה והמשוב |

| `assets/responsive-slides.pdf` | עותק המצגת שסופקה כמקור |

ה־HTML בעורך הוא תוכן ה־body בלבד. מעטפת HTML, תגית viewport וסגנון בסיס נוספים אוטומטית; אפשר לראות את סגנון הבסיס בפרטי כל מעבדה, והוא נכלל גם בקובץ המורד. הכוונה היא לעריכת דוגמאות מקומיות, ולא להטמעת ספריות חיצוניות או להרצת שרת.

## שמירה ופרטיות

אין שירות ניתוח, מסד נתונים, שליחת תשובות או קריאות רשת מהלוגיקה. רק שישה סימוני השלמת פרק נשמרים ב־localStorage תחת `responsive-learning-completed-v1`. הסימון אינו נקבע לפי תשובות נכונות. תשובות ועריכות קוד נשארות בזיכרון העמוד, נשמרות במעבר בין פרקים ומתאפסות ברענון. לשמירת קוד משתמשים ב״הורדת הקוד״. אם השמירה המקומית חסומה, מוצגת הודעה והלמידה ממשיכה.

קוד הלומדים רץ בתוך iframe עם `sandbox="allow-scripts"`, ללא `allow-same-origin`. מדיניות CSP מגבילה את טעינת המשאבים לקוד ולתמונות נתונים מקומיות. שגיאות JavaScript רגילות מדווחות מחוץ לתצוגה, ונבדקים מקור ההודעה ומזהה ההרצה לפני הצגתן. שגיאות CSS עשויות להידחות בשקט על ידי הדפדפן; אין כאן מנתח שגיאות CSS מלא. אין אפשרות להבטיח התאוששות בתוך העמוד מלולאה אינסופית שהלומד כתב.

## רענון מטמון בכל עדכון

גרסת הנכסים הנוכחית היא `20261103.2`. בכל שינוי העלו את מספר הגרסה בכל פרמטרי `?v=` ב־`index.html`, את הכיתוב בתחתית ואת `version` ב־`lessons.js`. לדוגמה: `20261103.3`. כך קובצי CSS/JS והנכסים מקבלים כתובת חדשה אצל לומדים שכבר פתחו את היחידה. אין Service Worker.

לאחר העלאה פתחו את כתובת האתר עם פרמטר חדש, למשל `?v=20261103.3`, ורעננו. פרמטר בדף לבדו אינו מחליף את שינוי גרסאות קובצי ה־CSS/JS. אין לשנות את שם מפתח ההתקדמות בעדכון תוכן רגיל.

## מקורות ושיקולים פדגוגיים

מקור התוכן הוא המצגת שסופקה, שקפים 2–24. ניסוח ותרגול הותאמו ללמידה עצמית קצרה. הדוגמאות עוסקות בסדנאות בקמפוס. תפריט המצגת הורחב לעדכון `aria-expanded`, לסגירה ב־Escape, לניהול מיקוד בשינוי רוחב ולשמירת קישורים זמינים אם JavaScript של הדוגמה אינו פעיל. הובהר ש־flex-grow מחלק מקום פנוי, ושאחוזים ו־em תלויים בתכונה. אין הוראת Bootstrap בתוכן.

מקורות השלמה: [MDN: רספונסיביות](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design), [Viewport](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/viewport), [flex-grow](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/flex-grow).

בדיקות חזותיות בדפדפן מיועדות לביצוע ידני לפי המדריך; לא הופעלה שליטה בדפדפן לצורך בדיקה. אין להציג את ההתאמות שבקוד כהסמכת נגישות לפני הבדיקות הידניות.
