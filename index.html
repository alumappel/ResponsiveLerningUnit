01 / רספונסיביות ו־Viewport

פיתוח אתרים
רספונסיביים

אתר רספונסיבי מתאים את הפריסה שלו לרוחב התצוגה. ביחידה זו נלמד להתאים רכיבים, תפריט, תמונות וטקסט בעזרת HTML, CSS ו־JavaScript.

RESPONSIVE LAYOUT● ● ●

שלושה כרטיסים בשורה בתצוגה רחבה ובעמודה בתצוגה צרה.

מטרות הלמידה

לסדר רכיבים, לשנות פריסה לפי רוחב, לפתוח תפריט בנייד ולהתאים תמונות וטקסט.

הנחיות ללמידה

בכל פרק הסבר, דוגמה שניתנת לעריכה ושאלות ווידוא הבנה. קראו את התכנים וענו על השאלות, לאחר מכן נשוחח על החומר בכיתה.

תפקידי HTML, CSS ו־JavaScript

HTML מגדיר את התוכן והמבנה, CSS את המראה והפריסה, ו־JavaScript את ההתנהגות. ברספונסיביות רוב העבודה היא ב־CSS; ניעזר ב־JavaScript רק כשהמשתמש מפעיל פעולה. כדי לייצר אתרים שניתן להשתמש בהם ברוחבי תצוגה שונים, אפשר לעבוד בשתי גישות:

רספונסיבי

פריסה גמישה

התוכן זורם בהתאם לשטח הזמין. ברוחבים מסוימים אפשר לשנות גם את המבנה, למשל משורה לעמודה.

אדפטיבי

פריסות מוגדרות מראש

בוחרים בין כמה פריסות מוכנות לפי תנאים. בפועל אפשר לשלב בין הגישות; כאן נתמקד בפריסה רספונסיבית.

הגדרת אזור התצוגה: Viewport

ה־viewport הוא אזור התצוגה של הדף בדפדפן. הוא עשוי להיות צר יותר מהמסך כולו. בטלפון, תגית זו ב־<head> מנחה את הדפדפן להשתמש ברוחב המכשיר ביחידות CSS, עם הגדלה התחלתית של 1:

<meta name="viewport" content="width=device-width, initial-scale=1">

התגית אינה הופכת את העיצוב לרספונסיבי בעצמה. צריך גם CSS מתאים. השאירו למשתמשים אפשרות להגדיל את הדף; אל תוסיפו user-scalable=no.

רוחב קבוע ורוחב גמיש

מיכל הוא רכיב שמכיל רכיבים אחרים. width: 600px קובע לרכיב רוחב של 600 פיקסלי CSS, גם כשהמיכל שלו צר יותר. width: 100% מתאים את הרוחב לרוחב המיכל. אפשר להוסיף max-width: 600px כדי שהרכיב יישאר גמיש, אך לא יגדל מעבר ל־600 פיקסלים.

.box {
  width: 100%;
  max-width: 600px;
}
הדגמה ותרגול

השוואת רוחב קבוע לרוחב גמיש

בחרו רוחב של 360 פיקסלים. הקופסה הראשונה קבועה ברוחב 600 פיקסלים; השנייה גמישה. איזו מהן תחרוג? לאחר מכן החליפו ב־CSS את width: 600px ב־width: 100% והריצו.

02 / Flexbox

סידור רכיבים עם Flexbox

Flexbox הוא כלי CSS לסידור רכיבים בשורה או בעמודה. הגדרות המיכל משפיעות על הפריסה של הילדים הישירים שלו.

המיכל · Container

display: flex הופך את המיכל ל־Flex container. ‏flex-direction קובע את הכיוון. ‏gap מוסיף רווח.

הילדים הישירים · Items

אם ul הוא המיכל, רכיבי li הישירים שבתוכו הם הפריטים. הקישורים בתוך ה־li אינם פריטי Flex של אותו מיכל.

כיוון הפריסה ויישור הפריטים

justify-content מפזר פריטים לאורך הציר הראשי; align-items מיישר אותם בציר הניצב לו. ב־row הציר הראשי אופקי; ב־column הוא אנכי. בדף בעברית כיוון הכתיבה משפיע גם על תחילת השורה.

חלוקת המקום הפנוי עם flex-grow

לאחר הקצאת המקום הראשוני לפריטים, ייתכן שנותר במיכל מקום פנוי. flex-grow הוא מספר שקובע באיזה יחס תחולק התוספת בין הפריטים. פריט עם flex-grow: 4 יקבל פי ארבעה מהתוספת שיקבל פריט עם flex-grow: 1. זהו יחס בין התוספות, ולא בהכרח בין הרוחבים הכוללים של הפריטים.

לדוגמה, אם לשני פריטים גורמי גדילה 4 ו־1, ויש 100 פיקסלים פנויים לחלוקה, הראשון יקבל תוספת של 80 פיקסלים והשני תוספת של 20 פיקסלים. לכל פריט נוסף המקום שקיבל על גבי גודל הבסיס שלו.

הדגמה ותרגול

שינוי כיוון הפריסה ויישור הקישורים

  1. שנו flex-direction: row ל־column והריצו. מה קרה לקישורים?
  2. החזירו ל־row, שנו justify-content ל־space-between והריצו שוב.
תרגול נוסף: שינוי flex-grow

הוסיפו .links > li { flex-grow: 1; } וגם .links > li:first-child { flex-grow: 4; }. הפריט הראשון יקבל פי ארבעה מהתוספת של המקום הפנוי שכל פריט אחר מקבל. זו אינה הבטחה שרוחבו הכולל יהיה פי ארבעה, כי גם גודל הבסיס והתוכן משפיעים.

03 / Media Queries

שינוי פריסה עם Media Queries

Media Query מאפשר להפעיל כללי CSS רק כאשר תנאי מסוים מתקיים. כאן נשתמש בתנאי רוחב כדי להציג כרטיסים בעמודה בתצוגה צרה ובשורה בתצוגה רחבה.

Mobile first: בסיס לתצוגה צרה והתאמות לתצוגה רחבה

כותבים קודם את כללי הבסיס למסך צר. אחריהם מוסיפים @media עם min-width כדי לשנות רק את מה שנחוץ במסך רחב. הכללים מחוץ לשאילתה ממשיכים לחול גם ברוחב גדול.

.cards { display: flex; flex-direction: column; }
@media (min-width: 768px) {
  .cards { flex-direction: row; }
}
נקודת שבירה (Breakpoint) היא הרוחב שבו משנים את העיצוב. min-width: 768px כולל גם 768 בדיוק; max-width: 600px כולל גם 600. בוחרים נקודות לפי צורכי התוכן, ולא כהבטחה לזיהוי טלפון או מחשב.

בדוגמה, עד רוחב 767 פיקסלים הכרטיסים מוצגים בעמודה. ברוחב 768 ומעלה מופעל הכלל שבתוך השאילתה, והכרטיסים מוצגים בשורה. שאר כללי הבסיס ממשיכים לחול.

הדגמה ותרגול

בדיקת הפריסה לפני נקודת השבירה ואחריה

בחרו 767 ואז 768 בבקרת הרוחב. הסתכלו גם על הכרטיסים וגם על הודעת מצב השאילתה. אחר כך שנו בקוד את 768 ל־900 והריצו; כעת בדקו ב־899 וב־900.

הסבר התחביר של Media Query

@media פותח תנאי. הסוגריים העגולים מכילים את התנאי; בתוך הסוגריים המסולסלים כותבים כללי CSS רגילים. השאילתה נבדקת מול רוחב התצוגה של הדף שבהדגמה, ולא מול רוחב כל יחידת הלמידה.

04 / תפריט רספונסיבי

תפריט רספונסיבי עם CSS ו־JavaScript

ברוחב צר נציג כפתור לפתיחת התפריט. ברוחב רחב הקישורים יופיעו בשורה, בלי צורך בכפתור.

חלוקת התפקידים בקוד התפריט

  1. HTML: כפתור אמיתי וניווט עם מזהה. aria-controls מחבר ביניהם; aria-expanded מתאר אם התפריט פתוח.
  2. CSS: במצב צר מסתירים את הקישורים עד לפתיחה. מ־768 פיקסלים מציגים אותם תמיד ומסתירים את הכפתור.
  3. JavaScript: לחיצה מחליפה מצב, מעדכנת מחלקה וגם את aria-expanded.

ציון מצב התפריט עבור טכנולוגיות מסייעות

לכפתור יש את המאפיין aria-controls="main-nav", שמפנה למזהה הניווט שעליו הוא שולט. המאפיין aria-expanded מתאר את מצב הפתיחה: false כשהתפריט סגור, ו־true כשהוא פתוח. כך קורא מסך יכול להודיע למשתמש אם התפריט פתוח או סגור.

בעת לחיצה, ה־JavaScript מעדכן שני דברים: את המחלקה is-open, שקובעת אם הקישורים מוצגים בתצוגה צרה, ואת הערך של aria-expanded בכפתור. לדוגמה, בפתיחה:

nav.classList.add('is-open');
button.setAttribute('aria-expanded', 'true');
הדגמה ותרגול

בדיקת התפריט בתצוגה צרה ורחבה

בחרו 360, לחצו על ״תפריט״ בתוך ההדגמה, ואז בדקו גם עם המקלדת: Tab למעבר, Enter לפתיחה ו־Escape לסגירה. עברו ל־1024 וחזרו ל־360: התפריט חוזר למצב סגור. בלשונית JS מצאו את השורה שמעדכנת aria-expanded.

שמירה על גישה לקישורים. כאן מסתירים קישורים רק כאשר יש דרך לפתוח אותם. אין להעלים תוכן חיוני בנייד בלי להציע אליו גישה. סדר הקישורים ב־HTML נשמר גם כשהפריסה משתנה.

05 / תמונות רספונסיביות

התאמת תמונות לרוחב המיכל

תמונה ברוחב טבעי גדול עלולה להרחיב את התוכן מעבר למיכל. שתי הגדרות קצרות שומרות אותה בתוך הגבולות.

הגבלת רוחב התמונה עם max-width

img {
  max-width: 100%;
  height: auto;
}

max-width: 100% מגביל את הרוחב המרבי של התמונה לרוחב המיכל. אם התמונה גדולה מהמיכל, היא תוקטן כדי להיכנס אליו. אם היא קטנה ממנו ולא נקבע לה רוחב נוסף, היא יכולה להישאר בגודלה המקורי. לדוגמה, תמונה ברוחב טבעי של 200 פיקסלים במיכל של 500 פיקסלים לא תוגדל רק בגלל הגדרה זו.

שמירה על יחס הממדים עם height: auto

height: auto מתאים את גובה התמונה לרוחב שלה ושומר על היחס בין הרוחב לגובה. לדוגמה, תמונה בגודל 900×400 שתוקטן לרוחב של 450 פיקסלים תהיה בגובה 200 פיקסלים. גובה CSS קבוע של 400 פיקסלים במצב הזה היה מעוות את התמונה.

הדגמה ותרגול

בדיקת תמונה עם הגבלת רוחב ובלעדיה

ברוחב 360 התמונה נכנסת למסגרת. שנו את max-width ל־none, הריצו וגללו בתוך ההדגמה כדי לראות את החריגה. החזירו ל־100%. מה נפתר בלי לשנות את קובץ התמונה?

לסרטון מקומי אפשר להשתמש גם ב־video { max-width: 100%; height: auto; }. להטמעה כמו iframe מתאים בדרך כלל מיכל עם aspect-ratio. זו התאמת פריסה; בחירה בקובץ תמונה קטן יותר לנייד היא נושא נוסף.

06 / טקסט ויחידות מידה

גודל טקסט ויחידות מידה

יחידות מידה ב־CSS קובעות כיצד מחושבים גדלים. חלקן מבוססות על גודל גופן, אחרות על המיכל או על אזור התצוגה.

חישוב גודל טקסט עם rem

רכיב השורש של המסמך הוא html. יחידת rem מתייחסת לגודל הגופן שמוגדר בו. אם גודל הגופן בשורש הוא 16 פיקסלים, 1rem שווה ל־16 פיקסלים ו־2rem ל־32. אם נשנה את גודל השורש ל־20 פיקסלים, 2rem יהיו 40 פיקסלים.

יחידות מידה נפוצות

משמעות יחידות המידה ודוגמאות לשימוש
יחידה ביחס למה? דוגמה
px פיקסל CSS, שאינו בהכרח פיקסל פיזי יחיד במסך border: 1px solid
rem גודל הגופן של רכיב השורש html אם השורש 16px, אז 2rem הם 32px
em ב־font-size: גודל הגופן שהתקבל בירושה. בתכונות כמו padding: גודל הגופן של הרכיב עצמו padding של 1em ברכיב עם גופן 20px הוא 20px
% תלוי בתכונה; ב־width, בדרך כלל רוחב המיכל המכיל width: 80%
vw / vh 1vw הוא 1% מרוחב ה־viewport; ‏1vh הוא 1% מגובהו width: 80vw
הדגמה ותרגול

השפעת גודל גופן השורש על רכיבים שמוגדרים ב־rem

כותרת ההדגמה היא בגודל 2rem, והפסקה בגודל 1rem. שנו את גודל השורש מ־16px ל־20px והריצו. מה יהיה גודל כל אחד מהם? השוו לתווית בגודל 16px שנשארת קבועה.

הקשר בין יחידות מידה לרוחב התצוגה. ‏rem תלוי בגודל גופן השורש, ולא ישירות ברוחב התצוגה. אפשר לשנות את גודל השורש באמצעות Media Query. בממשק אמיתי כדאי לכבד גם העדפות גופן של המשתמש, למשל באמצעות html { font-size: 100%; }, ולבדוק הגדלה ושבירת שורות.
סיכום

עקרונות לפיתוח אתר רספונסיבי

מגדירים Viewport, משתמשים במידות גמישות וב־Flexbox, ומשנים פריסה באמצעות Media Queries. מתאימים את התפריט לרוחב התצוגה, מגבילים את רוחב התמונות ובוחרים יחידות מידה מתאימות לטקסט. בודקים את התוצאה בכמה רוחבים ומוודאים שהתוכן והפעולות נשארים זמינים.

אפשר לחזור לכל פרק ולנסות שוב. התשובות לשאלות נשארות רק כל עוד העמוד פתוח; שינויי הקוד נשמרים רק עד לרענון.
